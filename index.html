Democratizing Artificial Intelligence for Local Impact

Traditionally, computer vision required expensive GPU clusters, cloud subscriptions, and specialized engineering teams. By combining Google Teachable Machine with static web hosting on GitHub Pages, anyone in the community can build, share, and deploy meaningful AI tools for free.

Inclusive STEM Education

Students and teachers can train custom visual models in minutes—learning how training data, bias, and confidence thresholds work hands-on without complex coding setups.

Architecture & Craft

All 7 Core Principles of Design Applied

Every visual and interactive decision in this interface follows foundational graphic and UI/UX design principles to maximize clarity, trust, and usability.

Interactive Reference: Click any principle to highlight its role
01 / HIERARCHY

Visual Hierarchy

Clear typographic scale guides the eye from the hero headline to the live AI studio, top predicted label, and secondary probability bars.

02 / BALANCE

Balance & Alignment

Asymmetrical 7:5 studio split pairs heavy visual video weight on the left with structured data cards on the right along a strict 12-column grid.

03 / CONTRAST

High Contrast

Crisp white typography and luminous emerald/indigo active indicators stand out cleanly against deep obsidian surfaces for effortless legibility.

04 / EMPHASIS

Focal Emphasis

The interactive camera viewport and the "Top Detected Class" badge use elevated borders, glow accents, and larger typography as primary focal points.

05 / PROPORTION

Proportion & Scale

Harmonious 16:9 viewport ratios, modular padding scales, and real-time confidence bars visually encode exact percentage proportions.

06 / RHYTHM

Rhythm & Repetition

Consistent rounded-2xl card geometry, uniform icon badges, and repeating prediction meter rows establish a predictable visual cadence.

07 / UNITY & HARMONY

Unity, Harmony & Whitespace

A cohesive slate-indigo-emerald color system, paired Inter + JetBrains Mono typefaces, and generous breathing room unify the AI model, community mission, and interface into one seamless experience.

Host on GitHub Pages in 60 Seconds

  1. Create a new public repository on GitHub (e.g., ai-community-vision).
  2. Save this exact single-file code as index.html in the root of your repository.
  3. Open Settings → Pages in your GitHub repository.
  4. Under Build and deployment, select Deploy from a branch → main (/root) and click Save.
  5. Remember: GitHub Pages automatically serves over HTTPS, which is required by browsers to unlock webcam access!
